# ONE — Product Roadmap & Epics

## Epic Structure (12 Epics)

### EPIC 1 — Product Foundation & Local-First Architecture
* Setup repository, build tooling (Vite + React 19 + TypeScript + Tailwind CSS).
* Core state machine and IndexedDB (Dexie) storage engine.
* Web Worker precision timer and Web Audio harmonic synthesizer.

### EPIC 2 — Calm UX & Design System
* Accessible color tokens, typography hierarchy, responsive layout.
* Keyboard navigation shortcuts (`Cmd/Ctrl+K`, `Space`, `Esc`).
* Micro-animations respecting `prefers-reduced-motion`.

### EPIC 3 — Focus Engine & ONE THING MODE
* "What matters right now?" intention prompt with presets.
* Duration presets (15, 25, 45, 60, 90m, custom) and Protection Levels (1–5).
* ONE THING MODE screen with circular progress arc and subtle breathing pulse.

### EPIC 4 — Intent Firewall & Mindful Interception
* Contextual interception modal: "WAIT. You said: [Goal]."
* Three pathways: Distraction recovery, intentional exception passes, emergency exit.
* Timed exception passes (2m / 5m) with active countdown banner.

### EPIC 5 — Distraction Recovery & Distraction Inbox
* Distraction Inbox ("Save for Later") for cognitive offloading (Zeigarnik buffer).
* Recovery Latency engine (measuring drift-to-return duration).
* Focus Rescue ("Rescue Me") for compassionate mid-day resets.

### EPIC 6 — Analytics & Personal Focus Profile
* Daily Attention Report (Intentional Time, Deep Focus, Recovered Time, Recovery Speed).
* Accomplished outcomes registry.
* Non-judgmental behavioral observations and peak focus windows.

### EPIC 7 — Privacy & Security Architecture
* 100% on-device storage guarantee.
* One-click JSON data export and instant database wipe.
* Web Crypto API client-side encryption readiness.

### EPIC 8 — Platform Integrations & Bridges
* Web Extensions Manifest V3 bridge.
* System notifications and screen wake lock.
* Desktop wrapper support (Tauri / Electron).

### EPIC 9 — AI Intent & Reflection Assistant
* Quiet, non-intrusive AI outcome summarizer and goal clarifier.
* Distraction pattern synthesis without cloud data leaks.

### EPIC 10 — Comprehensive Quality & Testing
* Unit tests for FSM, timer accuracy, and storage operations.
* Integration tests for full vertical slice.
* Accessibility and performance benchmarking.

### EPIC 11 — Production Build & Deployment
* Static PWA deployment configuration.
* Service Worker caching for complete offline operation.

### EPIC 12 — Growth & Social Accountability (Focus Together)
* Silent co-focus rooms without feeds or likes.
* Peer accountability mechanisms.
